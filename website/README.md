# AVU homepage mockup

A one-page mockup of the new avu.wine homepage, built from the website brief.

- `index.html` holds the whole page: styles, copy and scripts. It is written for publishing as a claude.ai artifact, so it has no `<html>`, `<head>` or `<body>` tags of its own.
- The films are simulated in the browser: each one moves a camera across still photos and cross-fades between them. Final films will come from Higgsfield Cinema Studio.
- Photos are not in this repository. They are Marco Reggi's photos of the AVU SA Building, The Wine Shop and The Wine Club, licensed to AVU, and this repository is public. Put them in `assets/photos/` with the file names the page uses (for example `b-wide.jpg`, `shop-facade.jpg`, `club-table.jpg`); that folder is ignored by git.
