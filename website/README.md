# AVU website mockups

Mockups of the new avu.wine, built from the website brief and the AVU Website Terms of Reference.

- `site.html` is the full-site mockup: the ten pages of the agreed sitemap (Home, Producers, Rare Bottles, Stock & Storage, Personal Wine Butler, Worldwide Delivery, The Wine Club & Experiences, Membership, About AVU, Contact), switched by the `#name` in the address.
- `index.html` is the earlier one-page homepage mockup.
- `assets/avu/` holds the CSS and scripts from the avu-aesthetic skill (`.claude/skills/avu-aesthetic/assets/`); copy them again after changing the skill.
- Both pages are written for publishing as claude.ai artifacts, so they have no `<html>`, `<head>` or `<body>` tags of their own.
- The films are simulated in the browser: each one moves a camera across still photos and cross-fades between them.
- Photos are not in this repository. They are Marco Reggi's photos of the AVU SA Building, The Wine Shop and The Wine Club, licensed to AVU, and this repository is public. Put them in `assets/photos/` with the file names the pages use (for example `b-wide.jpg`, `shop-facade.jpg`, `club-table.jpg`); that folder is ignored by git.
